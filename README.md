# 1. Project Title

📊 **Netflix Content Analysis Dashboard | Python & Power BI**

An interactive data analysis project designed to explore Netflix-style content, including movies, TV shows, release years, ratings, genres, countries, and directors.

# 2. Short Description

The Netflix Content Analysis Dashboard is a data analytics project that uses Python and Power BI to explore a Netflix-style dataset containing approximately 5,000 records. It focuses on data cleaning, exploratory data analysis (EDA), content distribution, genre analysis, ratings, and release-year trends. The project transforms raw data into meaningful insights through data processing, visualizations, and an interactive dashboard.

# 3. Tech Stack

The project uses the following tools and technologies:

- 🐍 **Python** – Data analysis and preprocessing.
- 🐼 **Pandas** – Data cleaning, transformation, grouping, and analysis.
- 🔢 **NumPy** – Numerical calculations and statistical operations.
- 📈 **Matplotlib** – Data visualization and charts.
- 📊 **Power BI Desktop** – Interactive dashboard development.
- 🧹 **Power Query** – Data transformation and preparation for Power BI.
- 🧮 **DAX** – KPI calculations and analytical measures.
- 📓 **Jupyter Notebook** – Interactive coding, analysis, and documentation.

# 4. Key Project Features

- **Content Type Analysis:** Compare the distribution of Movies and TV Shows.
- **Release-Year Analysis:** Explore content distribution across different release years.
- **Rating Analysis:** Analyze content-rating categories and their frequency.
- **Genre Analysis:** Identify the most frequently listed genres.
- **Country Analysis:** Explore the countries associated with content.
- **Director Analysis:** Identify directors appearing most frequently in the dataset.
- **Data Cleaning:** Handle missing values, duplicate records, and incorrect data types.
- **Interactive Dashboard:** Use KPI cards, charts, and slicers to explore content trends in Power BI.

# 5. Key Performance Indicators (KPIs)

The dashboard can display the following KPIs:

- **Total Titles:** Total number of records after cleaning.
- **Total Movies:** Number of Movie records.
- **Total TV Shows:** Number of TV Show records.
- **Unique Release Years:** Number of distinct valid release years.
- **Most Common Rating:** The most frequently occurring rating category.
- **Top Genre:** The most frequently listed genre.

*Note: KPI values should be calculated from the cleaned dataset. They may change when dashboard filters are applied. Do not use unverified figures as final results.*

# 6. Business Insights

- Compare the number of Movies and TV Shows in the dataset.
- Identify common release periods and content-rating categories.
- Discover frequently appearing genres and countries.
- Explore director representation within the dataset.
- Use interactive filters to investigate content by type, year, country, and rating.
- Present data patterns through visualizations to support easier interpretation.

# 7. Learning Outcomes

- Gained practical experience in data cleaning and preprocessing using Pandas.
- Practiced numerical analysis using NumPy.
- Developed data visualization skills using Matplotlib.
- Performed exploratory data analysis (EDA) on a structured dataset.
- Learned to create KPI measures and interactive reports in Power BI.
- Improved skills in communicating analytical findings through charts and dashboards.

# 8. Conclusion

This project demonstrates an end-to-end data analytics workflow, from data cleaning and exploratory analysis in Python to interactive dashboard development in Power BI. It helps develop practical skills in data preparation, visualization, and insight generation for entry-level Data Analyst roles.

**Dataset Note:** This project uses a synthetic Netflix-style dataset created for educational and portfolio purposes. It does not represent the official Netflix catalogue or verified Netflix business statistics.
